# โรงพยาบาลพลับพลาชัย — ต้นแบบหน้าบ้าน

Next.js + React + TypeScript พร้อม API, Prisma และ JWT ของระบบเอง ใช้ PostgreSQL บน Supabase ชั่วคราวโดยไม่ใช้ Supabase Auth รายละเอียดตั้งค่าและข้อจำกัดล่าสุดอยู่ใน [SETUP.md](SETUP.md) ระบบจริงยังรอกรอก env และทดสอบกับบัญชีจริง

## เริ่มใช้งาน

ใช้ Node.js 20.9 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:3000

```sh
npm run typecheck
npm run build
npm start
```

## หน้าที่มี

- หน้าแรก: บริการ → ประชาสัมพันธ์ → แผนที่และข้อมูลติดต่อ → Footer
- ข่าวประชาสัมพันธ์: ค้นหา แยกหมวดหมู่ และเปิดอ่านเนื้อหาตัวอย่าง
- ITA: สถานะว่างสำหรับเอกสารที่จะเผยแพร่
- รวมลิงก์: หมวดประชาชน บุคลากร และหน่วยงานที่เกี่ยวข้อง
- เกี่ยวกับโรงพยาบาล และปุ่มเข้าสู่ระบบที่แจ้งสถานะว่ายังไม่เชื่อมต่อ
- เมนูมือถือ การใช้งานคีย์บอร์ด และปุ่มเพิ่มขนาดตัวอักษร

ใช้ hash navigation เช่น /#ita และ /#news เพื่อเปิดหน้าโดยตรง

## ข้อมูลที่ต้องยืนยันก่อนใช้จริง

ข่าว รายการบริการ และข้อมูลหน่วยงานในต้นแบบไม่ใช่ประกาศทางการ แผนที่ใช้ Leaflet กับ OpenStreetMap แสดงภาพรวมประเทศไทยจนกว่าจะตั้งพิกัดที่ยืนยันแล้ว ภาพ hero เป็นภาพสร้างด้วย AI และระบุไว้ในภาพ ไม่ใช่บุคลากรจริงของโรงพยาบาล เครื่องหมายหัวใจเป็นเครื่องหมายชั่วคราว ไม่ใช่ตราทางการ

เปลี่ยนภาพเป็นภาพจริงที่โรงพยาบาลอนุญาตให้ใช้ เปลี่ยนตราเป็นตราทางการ เติมที่อยู่ โทรศัพท์ อีเมล และแผนที่จริงก่อนเผยแพร่สู่สาธารณะ

คัดลอก .env.example เป็น .env.local เพื่อใส่ข้อมูลติดต่อที่ยืนยันแล้ว ค่า NEXT_PUBLIC_* แสดงต่อสาธารณะ ห้ามใส่รหัสลับ

## Deploy (อัปเดต)

ใช้ Node.js และพื้นที่เก็บ PDF ถาวรตาม SETUP.md ส่วนลิงก์ Sites เดิมเป็นหน้าบ้านเวอร์ชันก่อนหน้า ยังไม่ได้ Deploy backend หรือเชื่อมโดเมนทางการ

## ระบบจัดการข้อมูล

JWT เป็นของระบบเอง รหัสผ่านใช้ scrypt, ข้อมูลผ่าน Prisma, รูปใช้ Cloudinary, PDF เก็บเป็นไฟล์ส่วนตัว อ่านขั้นตอนใน SETUP.md
